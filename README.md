# Task 3: Employee Salary Analysis

## Aim
Practise numerical data processing in Python by analysing employee salaries.

## What the notebook does
- Stores a manually created list of 8 employees with their department and salary.
- Calculates the total, average, highest and lowest salary using built-in Python functions.
- Checks each result against the original data.
- Answers the three interview questions, including how to do the same analysis with Pandas.

## Results
| Measure | Value |
|---|---|
| Total salary | 436,000 |
| Average salary | 54,500.00 |
| Highest salary | 72,000 |
| Lowest salary | 38,500 |
